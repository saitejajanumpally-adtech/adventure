PET IMAGES GO IN THIS FOLDER

Name every file like this:   petname-mood.webp      (or .png)
Examples:                    penguin-hello.webp   panda-celebrate.webp   cat-oops.png

Pet names (lower case):  penguin  panda  cat  elephant  rabbit  tiger  bear  dog

Moods (start with the first eight):
  hello       waving. Login, tour, first visit, greeting
  explain     pointing or presenting. Game intros, how-to-play, tour slides
  celebrate   jumping for joy. Perfect round, level up, mission complete
  happy       calm and smiling. Default, top bar, scorecard
  think       thinking pose. Hints and waiting
  correct     cheering. Right answer
  oops        gentle "oh no", never harsh. Wrong answer
  encourage   supportive nod. Low score, out of lives
  proud       thumbs up. Good result (70 percent or more)
  streak      with a flame or sparkle. Streak milestones
  sleepy      yawning. Welcome back after a few days away
  hurt        wincing. Lost a life

Image rules:
  - Transparent background, square, about 600 x 600 pixels
  - WebP or PNG, under 100 KB each
  - Same art style, same size, same ground line for every image
  - No text inside the image

You do NOT need all of them. If a mood is missing the app uses the pet's "happy" image,
then "hello", then an emoji. So you can start with just  penguin-hello.webp  and so on,
and add more over time. No rebuild is needed: upload the files to the pets folder on GitHub.

Motion (bounce, wave, shake) is added by the app, so draw still images.
