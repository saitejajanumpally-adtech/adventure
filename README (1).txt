PET IMAGES LIVE IN THIS FOLDER

72 images are included: 8 pets x 9 moods, named petname-mood.webp
Pets:  penguin panda cat elephant rabbit tiger bear dog
Moods: hello explain celebrate happy correct oops encourage proud sleepy

To add more moods later (think, streak, hurt), save them here with the same naming,
for example  panda-think.webp , and upload to GitHub. No rebuild is needed.
If a mood is missing the app uses the pet's "happy" image, then "hello", then an emoji.

Image rules: transparent background, square, about 600 x 600 pixels, WebP or PNG, under 100 KB.
